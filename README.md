# 📂 Featured Projects

## 🤖 Aura Finance — AI-Powered Personal Finance Assistant

An AI-powered personal finance platform that transforms raw financial documents into categorized transactions, semantic financial search, spending insights, and intelligent recommendations.

### Tech Stack

`Next.js` `TypeScript` `Django REST Framework` `PostgreSQL` `OpenAI API` `Celery` `Redis` `pgvector` `JWT` `Cloudflare R2` `Docker`

### Highlights

- Developed a full-stack AI-powered personal finance platform using **Next.js** and **Django REST Framework**, enabling secure authentication, financial document processing, and intelligent transaction management.
- Built an AI-driven transaction extraction pipeline supporting PDF, CSV, and image-based financial documents using **OpenAI**, asynchronous processing with **Celery** and **Redis**, and hybrid rule-based parsing for improved accuracy.
- Implemented automatic transaction categorization, semantic transaction search, and similarity matching using **OpenAI embeddings**, **pgvector**, and **Retrieval-Augmented Generation (RAG)** techniques to provide personalized financial insights.
- Designed scalable RESTful APIs for uploads, transactions, budgeting, subscriptions, reports, and AI-powered search with **JWT authentication**, **PostgreSQL**, optimized queries, and **Cloudflare R2** object storage.
- Developed a responsive dashboard with real-time upload tracking, AI processing status, financial analytics, and intelligent spending recommendations while deploying the application using **Vercel** and **Railway**.
